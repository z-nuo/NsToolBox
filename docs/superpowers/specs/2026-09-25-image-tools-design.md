# 图片处理工具集设计

状态：首版已实现；2026-09-26 根据用户实际体验修正为独立工具。最低 macOS 14，继续提供 Intel / Apple Silicon Universal 2。体验验收状态统一见 [NST-026](../../development/TROUBLESHOOTING.md#nst-026)。

## 范围与布局

左侧新增「图片处理」，与开发工具并列；顶部为抠图、缩放、格式转换、压缩。四个标签是独立工具，各自持有图片列表、参数、错误和结果。切换后保留当前窗口各工具的内容；处理期间禁用图片工具切换，以保持串行操作。原先的共享组合流程已因跨工具继承抠图参数的问题替换。

工作区含批量图片列表、选中图片的原图 / 结果预览和紧凑参数栏。支持多文件选择、拖拽 PNG / JPG；显示尺寸、格式、体积、逐项状态和错误。透明背景用棋盘格表示。原图文件保留。

## 参数与导出

- 抠图：自动主体去背景 / 人像抠图，使用系统 Vision；全程本地，不上传图片、不下载第三方模型。不承诺每张图的识别效果；无主体或系统运行失败明确报告，不假造成功结果。输出透明 PNG，保留原尺寸。
- 缩放：原尺寸 / 百分比 / 指定宽高；宽高模式默认按比例适配边界，不裁剪，取消比例锁定后可拉伸；保留每张原图格式。
- 格式：PNG / JPG，默认 PNG 保留透明度；JPG 用用户选择的底色合成透明区域；只做格式转换，保留尺寸。
- 压缩：本页独立选择 PNG / JPG 格式、底色和 JPG 质量，保留原尺寸；PNG 无像素变换且方向正常时保留原文件字节；缩放、抠图或方向校正输出 8 位 sRGB，不承诺一定小于源文件。不提供“压到指定 KB”的精确目标功能。
- 每个工具只读取自身操作允许的参数，不运行其他工具步骤。缩放和格式转换的 JPG 编码质量固定为 0.95；用户可调质量集中在压缩工具。
- 每个工具内部批量统一参数，可逐张预览；参数变更使旧结果失效。运行时锁定参数与队列修改，提供取消（当前图的系统调用结束后生效）。单张失败继续后续图片。
- 成功结果保存到用户选择的目录，文件使用原名加 _processed；重名递增编号，复制时再次检查冲突。导出全部可用结果，失败项保留原因，可重新处理。临时结果只存在于当前会话，正常退出清理；崩溃或强制终止不保证清理。

「将此结果用于…」仅复制当前选中结果到目标工具，自动选中新输入，不自动执行。复制为独立快照，清空源工具或改变其参数不影响已传入图片。源结果重新生成后视为新输入，不会被旧结果的去重记录阻挡。导出沿用可读的原始名称。

## 实现与边界

ToolboxImages 使用 ImageIO / CoreGraphics / CoreImage / Vision，UI 通过串行后台工作队列调用；ImageWorkspaceModel 持有各工具独立的 ImageBatchModel，每次执行按工具构造专用参数。导入生成受限尺寸缩略图，处理结果写临时文件，避免把整批原图与结果同时保留在内存中。拒绝非 PNG/JPEG、多帧以及超出资源上限的输入，限制单张 4000 万像素、输出单边 16384 像素和 4000 万总像素；清楚显示限制原因。

原生通用去背景的 API 从 macOS 14 提供，当前 Intel 机器上已通过通用主体与真实人像推理验证；若系统算法不可用，显示具体失败及可行的人像模式，不能将人像分割作为通用分割伪装返回。Apple Silicon/macOS 14 实机矩阵如未执行须明确记录。

## 验收

生成测试图验证 JPG/PNG 编解码、EXIF 方向、透明合成、尺寸与比例、质量变化、非法文件、资源限制、无覆盖重名导出。队列验证单张失败隔离、取消、参数失效、重复文件与导出错误。原生窗口检查图片分类、四工具、列表、前后预览和最小尺寸。执行原有测试、图片测试与双架构打包，并核对所有最低版本配置与产物。

## 体验修正验收

先对无人物图执行人像抠图并失败，再切换格式转换导入另一张无人物图，必须能转换成功。切回抠图仍保留其错误与参数；转换、缩放和压缩不执行人物识别。显式结果传递、重新生成再传递与源缓存清理需回归验证。
