# 图片处理工具集设计

状态：用户已批准实现。最低系统由 macOS 13 调整为 macOS 14，继续提供 Intel / Apple Silicon Universal 2。

## 范围与布局

左侧新增「图片处理」，与开发工具并列；顶部为抠图、缩放、格式转换、压缩。四个标签编辑同一份处理参数，可组合执行一次流程：去背景 → 缩放 → 编码压缩 → 导出。切换工具集保留当前窗口中的图片和参数。

工作区含批量图片列表、选中图片的原图 / 结果预览和紧凑参数栏。支持多文件选择、拖拽 PNG / JPG；显示尺寸、格式、体积、逐项状态和错误。透明背景用棋盘格表示。原图文件保留。

## 参数与导出

- 抠图：不抠图 / 自动主体去背景 / 人像抠图，使用系统 Vision；全程本地，不上传图片、不下载第三方模型。不承诺每张图的识别效果；无主体或系统运行失败明确报告，不假造成功结果。
- 缩放：原尺寸 / 百分比 / 指定宽高；宽高模式默认按比例适配边界，不裁剪，取消比例锁定后可拉伸。
- 格式：PNG / JPG，默认 PNG 保留透明度；JPG 用用户选择的底色合成透明区域。
- 压缩：JPG 调整质量；PNG 无像素变换且方向正常时保留原文件字节；缩放、抠图或方向校正输出 8 位 sRGB，不承诺一定小于源文件。不提供“压到指定 KB”的精确目标功能。
- 批量统一参数，可逐张预览；参数变更使旧结果失效。运行时锁定参数与队列修改，提供取消（当前图的系统调用结束后生效）。单张失败继续后续图片。
- 成功结果保存到用户选择的目录，文件使用原名加 _processed；重名递增编号，复制时再次检查冲突。导出全部可用结果，失败项保留原因，可重新处理。临时结果只存在于当前会话，正常退出清理；崩溃或强制终止不保证清理。

## 实现与边界

ToolboxImages 使用 ImageIO / CoreGraphics / CoreImage / Vision，UI 通过串行后台工作队列调用。导入生成受限尺寸缩略图，处理结果写临时文件，避免把整批原图与结果同时保留在内存中。拒绝非 PNG/JPEG、多帧以及超出资源上限的输入，限制单张 4000 万像素、输出单边 16384 像素和 4000 万总像素；清楚显示限制原因。

原生通用去背景的 API 从 macOS 14 提供，当前 Intel 机器上已通过通用主体与真实人像推理验证；若系统算法不可用，显示具体失败及可行的人像模式，不能将人像分割作为通用分割伪装返回。Apple Silicon/macOS 14 实机矩阵如未执行须明确记录。

## 验收

生成测试图验证 JPG/PNG 编解码、EXIF 方向、透明合成、尺寸与比例、质量变化、非法文件、资源限制、无覆盖重名导出。队列验证单张失败隔离、取消、参数失效、重复文件与导出错误。原生窗口检查图片分类、四工具、列表、前后预览和最小尺寸。执行原有测试、图片测试与双架构打包，并核对所有最低版本配置与产物。
