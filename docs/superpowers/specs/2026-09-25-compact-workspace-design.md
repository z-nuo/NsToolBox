# NsToolBox 紧凑工作区界面规划

日期：2026-09-25。状态：用户已确认整体规划并批准实现；2026-09-25 进入开发与验证。

## 已确认的方向

- 左侧保留导航，内容改为工具集分类；现有工具归属「开发工具」。
- 具体工具位于主工作区顶部的横向二级工具栏：JSON、Base64、URL。
- JSON 格式化、压缩采用左侧输入、右侧结果；校验在相同双栏框架内展示报告。
- JSON 对比保留左右双栏输入、实时结构差异高亮和格式化两侧。
- Base64、URL 同样采用左侧输入、右侧结果，在操作区切换编码 / 解码。
- 视觉风格采用代码编辑器式的紧凑、高信息密度。
- 平台约束沿用 SwiftUI + AppKit、macOS 13+、Intel / Apple Silicon。

下列尺寸、配色、辅助控件与交互细节已随整体规划获准实现，最终效果通过真实窗口验收。

## 各工具的操作规则

### JSON

模式是互斥选择，输入后实时处理，不再同时添加用途重复的「执行」按钮。

| 模式 | 左栏 | 右栏 | 附加操作 |
| --- | --- | --- | --- |
| 格式化 | JSON 原文，可编辑 | 格式化结果，只读 | 结果复制 |
| 压缩 | JSON 原文，可编辑 | 压缩结果，只读 | 结果复制 |
| 校验 | JSON 原文，可编辑 | 校验报告：有效 / 无效，错误信息和位置 | 错误位置可定位左侧 |
| 对比 | 原始 JSON，可编辑 | 对比 JSON，可编辑 | 格式化两侧、差异列表 |

格式化、压缩、校验共享左侧输入；对比右侧文本单独保留，不能被格式化输出覆盖。切换模式不自动复制结果到原文。仅点击「格式化两侧」时改写对比输入，并保留撤销能力。

对比结果以低饱和背景和新增 / 删除 / 修改标记共同表达。编辑区下方提供可折叠的差异列表，默认折叠；折叠标题展示差异总数，展开高度默认 120，点击路径定位左右范围。存在任一侧解析错误时，不显示旧差异或误报「无差异」。维持对象忽略顺序、数组按序、数字精确比较的现有规则。

### Base64 与 URL

- 操作栏使用「编码 / 解码」互斥选择，输入后自动转换。
- 左侧原文可编辑，右侧只读，并明确标为编码结果或解码结果。
- 切换方向保留原始输入并重新计算，不隐式交换左右文本。
- 错误时保留输入，右侧清除过期输出并显示简短提示；错误详情可在底部查看。
- 沿用现有编码语义；URL 对参数值编码、加号不按空格处理等说明移入帮助提示。

### 复制与清空

- 可编辑面板标题栏提供「复制」「清空」；只读面板仅提供「复制」，避免清空后被实时计算重新填回。
- 「清空」只作用于所属输入；对比时两侧分别清空。移除含义不明确的页面级「清空」。
- 空内容时复制不可用；复制反馈短暂替换按钮文字，不改变按钮宽度。
- 工具切换保留当前窗口中的输入和模式；关闭窗口后的持久化仍不在本次范围。

## 视觉规范

以文字内容为主，工具标签、面板边界和选中态建立层级。「大乱炖」图标保留在应用身份位置，不在编辑区域加入装饰图案。

- 界面使用 macOS 系统字体，常规控件 12 pt，次要状态 11 pt。
- 编辑器使用系统等宽字体 13 pt，建议行高约 19 pt；JSON 保留语法着色，Base64 / URL 使用普通文本。
- 增加行号与轻微的当前行提示；长行允许水平滚动，行号按实际换行计数，不把折行算作新行。
- 按钮圆角约 4 pt；编辑面板使用直边和单像素分隔线，避免多层圆角卡片。
- 主题暂按跟随系统明暗；不增加自定义主题设置页。

暗色参考色：工作区 #20242B、导航和工具栏 #282D35、分隔线 #3B424D、正文 #E1E5EB、次要文字 #A7B0BE、选中强调 #74A9E8。浅色版使用系统背景与文字语义色保持同等层级；落地时检查文字对比度。

差异使用绿 / 红 / 琥珀低透明背景，同时提供文字与符号。键盘焦点、选中标签、禁用按钮都要有明确状态；紧凑不等于只能靠悬停发现操作，基础按钮保留文字与辅助功能名称。

## 空白、处理与错误状态

- 初始左栏提示「粘贴或输入文本」，右栏提示「结果将显示在这里」，不默认插入示例数据。
- 输入改变时立即使旧结果失效；短暂处理状态集中在底部，不能让过期结果看起来仍然有效。
- JSON 错误标明属于哪一侧、行列与原因；底部仅显示摘要，完整信息通过展开查看，避免挤压编辑区。
- 校验模式右侧报告是完整结果，底部仅显示简短结论。
- 普通工具切换不移动窗口尺寸；差异面板展开由用户触发，避免实时处理导致布局跳动。

## 规划验收与后续实现边界

本规划已获准实现。导航、尺寸密度、控件位置、校验报告与差异列表按下列标准验证。

后续验收至少检查：

1. 分类栏只呈现工具集，三个工具均在顶部切换；切换不丢输入。
2. 三个工具在默认与最小窗口下均保持可用双栏，按钮与状态不互相遮挡。
3. 格式化结果只读；对比两侧可编辑；校验错误可定位；复制和清空的作用对象明确。
4. 撤销、中文输入法、键盘导航、明暗外观与差异标记在真实窗口中验证。
5. 核心功能回归与 Universal 2 构建按实际变更执行；系统 API 或离屏截图不能代替视觉验收。

本次不扩展其他工具集、文件管理、云同步、编辑器插件、同步滚动或自定义主题。行号、拖动分栏、折叠差异列表属于本次已批准的界面能力。
