# 工具箱第一批扩展验证记录

日期：2026-09-26。环境：Intel、macOS 26.7、Swift 6.3.3、SDK 26.5。

实现提交：核心 `5d316c7`、图片 `126fa65`、界面 `8c49fb9`。范围来自用户批准的 [第一批扩展](../specs/2026-09-26-toolbox-expansion-proposal.md)，执行见 [计划](../plans/2026-09-26-toolbox-phase-one.md)。问题当前状态统一见 [开发问题指南](../../development/TROUBLESHOOTING.md)，不在本报告重复维护状态。

## 交付范围

- 图片裁剪（左上角像素矩形、常用比例）、90°旋转、双向翻转，保留PNG/JPG格式并生成预览供导出。
- 图片实际格式、尺寸、体积、色彩及alpha三类检查；16位极浅透明不会量化误判。
- 时间戳秒/毫秒与日期、显式时区，严格日期及夏令时歧义检查；UUID v4批量；UTF-8文本摘要。
- 纯文本行级增删高亮、差异导航、输入限制和过期异步结果保护。
- 普通文件批量重命名，预览、字面替换、前后缀、编号、列表排序、拒绝覆盖、逐项结果、会话撤销、TSV导出。
- 四个工具集：开发、图片、文本、文件。根视图持有独立模型，图片处理默认入口保持；PDF/OCR/水印等未纳入本批。

## 原生场景和显示检查

原生NSEvent覆盖图片独立操作、根工具集切换、开发六标签、文本输入与高亮、跨工具输入保留及原JSON/编解码操作。重命名测试实际创建临时文件，覆盖冲突、源替换、部分失败、连续改名、外部修改后的撤销拒绝和日志导出；不使用用户文件做写入验证。

已目视检查真实窗口截图中的图片信息（已读取、棋盘格、属性）、时间戳复制按钮、重命名预览；也检查图片编辑、文本差异与哈希、默认入口的NSView位图以及浅深色布局。所有临时样本/日志/截图在忽略的build目录；关键结果保留在本文件和问题指南。

## 边界与未执行

- Apple Silicon和macOS14实机未执行；双架构构建不能替代跨设备验证。
- 系统文件选择/保存面板未做新增人工点击验收；导入导出模型和实际临时文件操作已测。
- 时间戳日期展示精确到秒，重复/不存在的夏令时本地时间明确拒绝；哈希输入上限2MiB，文本对比每侧128KiB/2000行，UUID上限1000个。
- 图片编辑重新编码为8位sRGB；像素总量4000万、输出单边16384。8位alpha检查最多约160MB额外缓冲区，16位扫描每块最多2MiB；系统解码额外内存和整进程峰值未实测。
- 重命名预览/执行为同步文件操作，海量或缓慢外部卷的响应性能未压测；目录/符号链接、互占目标及纯大小写改名保守拒绝。RENAME_EXCL保证目标不覆盖，但源身份检查与路径改名不是同一个原子操作，元数据指纹不是内容哈希。
