## 审查发现与处理

1. Swift 的 Character 会将 CRLF 作为一个字符，逐字符比较 CR/LF 未正确移除 Base64 换行。修复为空白判断，并保留对应回归测试。
2. 防抖等待期间旧差异源范围仍会显示。现在每次输入或模式变化立即清除旧结果，并递增请求序号，只接收最新后台结果。
3. 文本存储属性着色可能影响撤销；改为 NSLayoutManager 临时属性，并测试语法色与撤销结果。
4. 多个正则分别着色会覆盖字符串内部的数字和关键字；改为单次词法匹配区分字段名、字符串、数字和常量。
5. 大整数经 Decimal/Double 中转会失真；保留数字词法文本，并使用精确十进制规范化比较。
6. 打包使用 SwiftPM 的 --show-bin-path 获取当前架构的准确路径，不使用可能选错架构的文件搜索回退。
