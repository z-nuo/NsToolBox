### NST-xxx · 问题标题

- **发现 / 更新日期**：YYYY-MM-DD / YYYY-MM-DD。
- **状态 / 来源**：待定位；用户反馈 / 实际错误 / 测试复现 / 审查发现。
- **环境与影响**：系统、CPU、Swift、SDK、Xcode/CLT、版本或提交、受影响功能。
- **现象与复现**：预期与实际差异、原始错误、入口、最小脱敏样例、操作顺序、出现频率；无法稳定复现时如实说明。
- **定位与根因**：已确认事实、证据、已排除项、未验证假设。
- **修复指南**：操作顺序与目的，说明对数据或系统进程的影响；未解决时写已尝试措施。
- **验证**：日期、命令、退出码或观察结果、原始场景是否恢复；区分测试、构建与用户端验收。未执行项及原因单列。
- **关联**：相对路径链接、测试函数、修复提交（提交后补充）、相关编号。
- **防复发 / 下一步**：回归保护、待验证项、阻塞条件。
